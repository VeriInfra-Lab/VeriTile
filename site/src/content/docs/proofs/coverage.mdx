The release gate covers the explicitly selected source and proof set. The
rest of the repository includes historical proofs, intermediate work and
benchmark drafts whose presence does not establish completion.
PRs check sources and regressions. The full selected Lean build and axiom
audit run daily at 04:00 Asia/Singapore (20:00 UTC), or on manual dispatch;
proof changes require that full validation locally before merge.

Three checks answer different questions:

- **Selected proof build:** the named Lean modules compile and their theorem
  dependencies pass the axiom audit. The public contracts retain their input
  domains, chosen models and any explicit numerical assumptions.
- **Function-body correspondence:** the registered Python JIT function bodies
  match their Lean quotations statement by statement. This check does not
  establish compiler correctness or hardware behavior.
- **Original-program acceptance:** the separate historical ledger includes
  wider source, host, native and numerical obligations. Pending reviews remain
  pending even when a selected proof or body comparison passes.
