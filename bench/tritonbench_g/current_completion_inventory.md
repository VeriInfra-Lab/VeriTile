## Verification boundary

Filesystem entries, Python AST JIT/call/write discovery, comment-stripped public Lean declaration discovery, review/source/support hashes, official selected-source extraction, and historical-ledger enumeration. No Lean elaboration, comparator replay or all-profile source certification is performed.

The user accepts normal input requirements and documented configuration/stage scopes, but not a replacement of floating arithmetic by real arithmetic. FP model adequacy is primary; an empty extra-law list is not completion, and relative equivalence is not absolute native functional correctness. Legacy scope_category labels describe coverage and do not count missing numerical assumptions. accepted_scope_review and numerical_obligations track actual numerical laws, existing evidence, pending bindings and idealizations independently. Accepted stage scope does not prove omitted source stages, GPU refinement or independent replay. Historical acceptance and direct JIT links do not establish current completion.

The report captures hashes of every discovered local Python/Lean file, per-task README and source-scope document, review/manifest/ledger input and discovery script. Freshness is checked before writing. These hashes bind this inventory; they are not proof replay receipts.
