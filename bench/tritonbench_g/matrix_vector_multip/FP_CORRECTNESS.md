# 浮点矩阵向量乘法

新增 `FPCorrect.lean` 验证完整原始循环源在单块配置 `0 < BLOCK_M`、`M ≤ BLOCK_M` 下的执行，包含 `M=0`，独立的初态值公式、读回和未写区域保持。旧公开数学结果的单块范围被具体化为原 kernel 的实际单次/空循环配置；这不是任意列数的完整多块归约证明。宽度、尾部mask和原有输出地址注入条件保留。

新的通用合同保留输入存储格式、显式fp32计算、padding转换、初始+0累加器、单独乘法和加法、fp32归约、输出格式转换。旧数学切片把初始 `0 + product` 化简成了 `product`；新证明没有沿用这种浮点下未经证明的简化。完整源擦除等式仅用于核对地址/控制形状。

`mv_one_block_software_fp32` 使用实际 `FP.Value .fp32`，每次加/乘独立舍入，以升序左折叠作为明确的软件sum配置，输出不依赖其余backend回调。`.real` 仅为显式fp32计算寄存器的擦除载体；`fp32↔.real`转换在此profile中保持既有32位值，并未把数学实数舍入定义为恒等。

仍待绑定实际GPU的归约树、舍入/FTZ、NaN策略、转换和融合选项。顺序软件sum不是对Triton实际归约顺序的断言；没有新GPU执行报告。
