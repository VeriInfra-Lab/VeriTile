# kv_cache_filling

Source: `kv_cache_filling.py` (TritonBench-G v1).

The typed contracts cover scale/zero metadata writeback and the originally
accepted K/V cache tile stages under the supplied fp32-state/uint8-cache profile.
`FPCorrect.lean::kv_metadata_typed_correctness` proves successful execution,
independent readback from the `MetaPre` input buffer and preservation outside
the active destination set. The destination retains the original loaded page
offset, block index, head stride and scale/zero slot. Its address condition is
injectivity only among active heads. Metadata values are not assumed outputs;
their quantizer/reduction producer is outside this accepted stage boundary.

`Proofs/TypedMetadata.lean::source_projection` recovers the exact existing
`fill_quant_meta_store_slice` after storage erasure. The source supports
homogeneous fp16, bf16, fp32, f8e4 and f8e5 storage annotations, plus an
abstract `.real` channel generated by the float64 annotation. The latter has
no native 64-bit floating storage binding. The floating carrier is opaque,
with no floating arithmetic, finiteness or rounding hypothesis.
`kv_metadata_bit_success` executes two active heads, preserves a negative-zero
payload, and checks an inactive head's sentinel. The raw fp32 load backend is
shared from `kcache_copy_triton/Proofs/TypedCopy.lean`.

`kv_k_uint8_typed_correctness` and `kv_v_uint8_typed_correctness` execute the
original selected SIDX/BIDX/KV_BLOCK_IDX tile shapes with symbolic dimensions,
strides and masks. The explicit final float-to-uint8 cast materializes the
Python store's destination conversion; the load/address/mask prefix has a
formal projection to each old accepted source. The supplied Python test
creates fp32 states and uint8 caches at lines 426–429, including quant_policy=0.
The result specifies the exact rational decoded from each input's IEEE bits,
truncation toward zero, the uint8 range, successful readback and the memory frame.
Active inputs must be finite and their truncated results must be representable;
negative fractions truncating to zero are allowed. NaN, infinity and overflow
are outside the defined active conversion domain. Negative zero converts to
integer zero. There is no rounding-to-nearest or saturation assumption.

The converter is totalized with an arbitrary policy on undefined conversions.
The proof shows complete observable memory is independent of that policy under
the active-lane domain; padding has no extra input restrictions. A nonempty
witness for both stage shapes converts 1.75 and 255.875 to 1 and 255, with an
inactive destination sentinel preserved. These are fixed-bit input examples,
not a reference program compared to itself.

This closes the accepted K/V tile conversion boundary, not the full production
kernel. The int4/int8 quantizer producers and full token loop remain outside
these contracts. Native GPU cast lowering, address arithmetic and the explicit
materialization of destination-store conversion still require backend binding.
No statement here equates an unbounded Real evaluator with machine conversion.

The accepted Nat address/metadata abstraction and finite-region/launch
obligations remain. No GPU experiment or CUDA refinement is claimed.
