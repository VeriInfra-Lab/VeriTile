# triton_linear_activation — checked whole-source repair

The production repair preserves the source's explicit `custom_fwd(cast_inputs=torch.float16)` AMP branch. Callers provide canonical FP32 CUDA X[M,K] or X[B,S,K], W[N,K], optional bias[N] and saved[M,N]. All used arguments share a device, have zero offsets and no lazy flags; nonempty active pointers are aligned and their complete backing intervals are pairwise separated. Empty M/N, K=0, every activation string and None are admitted subject to the retained source signed32 bounds. Named activations retain their source behavior; other strings and None use the source identity fallback. Sparse layouts are rejected before stride access. The contract is intentionally bounded to the existing canonical domain.

The source keeps all 98 configurations and default compiler arithmetic choices. The prior fixes for ragged store ownership, wrapped-gather hints, constexpr literal compatibility, empty launch skipping, rank-three reshaping, device scope and original saved-buffer identity are retained. AMP uses explicit half casts and a half saved scratch, then copies into the original FP32 saved tensor. No additional precision profile is inferred from fixtures.

`Contract.lean` proves equivalence of the accepted metadata domain and a checker that runs before effects, and derives the existing source-validity conditions. Metadata checks are grouped in the Lean checker: Python's exact exception-label ordering and raw rank/dimension extraction are interpretation boundaries, not claimed equivalent traces. `Binding` records ordinary object/storage/device observations and does not assume shape admission. `PhysicalBinding` connects those observations to actual backing intervals, pointers, capacities, native address extent and FP32 caller cells.

`Proofs/Checked/Host.lean` executes prepare, every autotuner trial, the selected kernel, copyback, reshape and save operations. Launch consumes the entered device state. Successful context exit restores the entry token on either body outcome. The actual reshape result is returned; save receives converted weight, optional bias and original-rank input in source order. `Entry.lean` puts validation and an actual ordinary allocator call before this program. The entry word map is bound to pre-call memory. Allocation failures and finite interrupted event prefixes are explicit outcomes, without universal launch-success assumptions.

The public `Checked.correct` theorem proves the independent dense Real output, saved preactivation, caller word frame and actual return/device/save behavior. `Checked.fp_equiv` derives full-call native word semantics using only nine scalar/cast numerical leaf families and one family of actual fixed K8/K16 ISA result lanes. `Checked.output_bytes` and `Checked.saved_bytes` use an independent raw-byte observer and one-cell codec law. `Checked.frame` proves the complete caller-backing exterior frame on every ordinary outcome, including arbitrary partial-byte tails after the saved logical prefix. Its premises are a one-event byte-span law and an ordinary allocator caller-byte frame, never a completed-call frame.

`Execution.lean` connects admitted dimensions to the retained signed32 source arithmetic and proves physical native pointer addition and allocation coverage for every byte of active caller/output cells. Historical `Machine.lean` covers all original grouped schedules, masked formed offsets and the final K-pointer increment. Historical source/event, all-K, whole-grid, cast/copyback and autotune-absorption proofs remain unchanged.

The preserved conditional implementation is `triton_linear_activation_conditional.py`; the old public proofs are `Proofs/ConditionalCorrect.lean` and `Proofs/ConditionalFPEquiv.lean`. `README.conditional.md` retains the previous scope. The original benchmark Python is byte-for-byte preserved. `source_pin.json` pins all three sources. `Kernels.candidateSHA256` belongs to the historical conditional source; the checked source hash is recorded by `Contract.lean` and the pin file.

Validation: 73 actual decorator/AMP/host cases, 10 host rejections, 588 grouped geometry cases and 588 independent dense cases; 319 actual repaired CPU Triton source/reference/frame cases, 7 additional rejections and 8 ordinary failure prefixes. The historical 1060 executable half-codec controls remain compiled. CPU libdevice tanh/erf are scalar NumPy/math adapters, and the interpreter's constexpr wrapper is unwrapped in the harness; these are not GPU libdevice evidence. Native scalar/ISA and exceptional-value conformance remains deferred as listed in `numerical-obligations.json`. The preserved compiler evidence is Triton 3.7.1 SM90 with 208 offline profiles; no new GPU numerical execution or verified Python/Triton compiler is claimed. Backward is absent from the original API.
