# Repaired RMS matmul and Q/K rotary

`rms_matmul_rbe_repaired.py` repairs the original QKV wrapper while retaining its 16×64×64 tile, four warps, four stages, FP16 Q output, FP16/raw-int8-E5M2 K/V outputs, and Q/K-only rotary epilogues. The original benchmark file is unchanged.

The named admission contract is `Contract.InputContract`; `Proofs/InputContract.lean` proves both directions of the Python guards, including the generator's unordered backing-storage comparisons. X is contiguous, resolved, aligned FP32 CUDA storage with shape `[B,M,K]`, K positive. All weights have shape `[N,K]`; the RMS vector has shape `[K]`. Weights, RMS, and supplied K/V use one common FP16 or int8 dtype. Int8 weights and outputs represent raw E5M2 payloads. All tensors share the input device. Head count is an exact positive Python int, head width an exact positive even Python int, and `N = heads * head_dim`. Supplied K/V may have any contiguous shape with `B*M*N` elements. Their returned views have shape `[B,M,heads,head_dim]` and preserve their pointers and storage offsets.

Start position accepts Python integers, including bool, in signed int64. For nonempty calls the last padded 16-row rotary position must also fit. Epsilon and theta are finite positive Python int/float scalars, including bool. Empty batch or row dimensions allocate/view the results and skip the launch. Offsets and noncanonical strides on unused singleton dimensions are admitted. The wrapper passes logical contiguous strides and makes no normalization copies, dtype transfers, or layout conversions.

The complete supplied output backings must be disjoint from each other and all read inputs. Overlapping read backings must share both their base pointer and dtype. Same-base, same-dtype aliases remain admitted, including tensors with distinct storage offsets. Overlapping imported backings with shifted base pointers, and mixed-dtype overlaps, are rejected as a conservative representation scope for the selected base-keyed word-storage model; readonly imported overlap is not intrinsically unsafe. These restrictions are executable guards, not hidden proof premises.

The kernel masks all K-tail loads; widens dimensions, strides, program IDs, lanes and position arithmetic; and computes ceil division using quotient plus remainder. Weights are promoted to FP32 for the selected FP32 input dot path. RMS moments and the dot accumulator stay FP32. Rotation uses adjacent normalized FP32 pairs, head-local frequencies, and the original position before the sole output conversion. Q/K are rotated; V is not. No 32-bit shape or 65,535-grid cap is added. Successful ordinary allocation/launch APIs remain a boundary; shared launcher limits are separate from the proved source index arithmetic. Inactive pointer expressions need not fit signed arithmetic because their masks produce no memory event.

`Kernels.lean` contains only the typed source translation. Historical arithmetic, geometry, word-reference, local-event, byte-frame and conditional host declarations are preserved under `Proofs/`; historical proof-heavy aliases moved to `Proofs/Program.lean`. `Proofs/Source.lean` pins the complete repaired AST and SHA-256. The new `Checked*` helpers derive shape validity, lane ownership and coverage, output injectivity/separation, active int64 arithmetic, aligned bounded physical loads/stores, and returned view metadata from the checked domain and ordinary Tensor/allocator facts. The public theorems do not require the historical narrower `HostDomain` or `IndexDomain`.

Public specifications are `rms_matmul_rbe_repaired_real_returns`, `rms_matmul_rbe_repaired_fp_returns`, and `rms_matmul_rbe_native_addresses`. The independent Real target is RMS-normalized GEMM and adjacent-pair rotary, with explicit scalar E5 representation ports. The native theorem gives actual physical bytes at returned pointers, a reference reading original input memory, every input's complete backing frame, and the frame outside logical stores in supplied K/V backings. Physical input bindings are per-scalar reads. Numerical correspondence assumptions are local scalar operations/conversions and one fixed m16n8k8 TF32 MMA output lane; there is no whole-matmul, whole-result, or exact-native-to-Real premise. The structural compiler boundary pins the typed source and lowered event graph; task coverage and addressing are proved separately.

Validation: all 24 task-local Lean modules and public axiom audits pass. `check_source.py` executes the actual wrapper/JIT AST on CPU storage: 13 QKV cases, 18 rejected calls, tails, offsets, singleton strides, empty dimensions, shared read weights, complete stores, and full backing frames. Alias controls admit same-base weight windows with distinct offsets and reject overlapping DLPack-imported backings with shifted base pointers. `check_lowering.py --output-dir /tmp/rms-qkv-lowering` passes eight offline SM80 profiles for FP16/E5, i32/u32/i64 scalar signatures and constexpr-one specializations. Emitted K loops use i64 induction and the selected TF32 MMA instruction. There is no GPU execution or native numerical-conformance claim.
