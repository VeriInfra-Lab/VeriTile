# Separate scalar-cast attention candidate

The mathematical target and arithmetic interpretations are fixed before new proof implementation. This candidate retains the six-buffer online attention API, grouped heads, independent nonnegative Q/K/V/O strides, all current INIT/END/window branches, raw continuation, empty NK and padded query stores. It keeps NK=1 admitted. Only the physical grid-y contract changes from Z*H<=65536 to Z*H<=65535; no total-grid product or segmented-launch condition is introduced.

For a program at query tile b and grouped head, the target reads only its initial Q/K/V and supplied raw O/M/L. It visits the exact source block sequence: the ordinary window uses the signed lower/upper clamps and block rounding; no-window and older-side complement use the full key range. The ordinary mask is 0<=row-key+offset<size, while complement is row-key+offset>=size. Padded keys/queries use source zero loads, and every BM-padded query row stores its result. INIT selects zero output, center -infinity and denominator one; otherwise the actual initial O/M/L are raw carry. END=false returns raw accumulator, center and denominator. END=true stores accumulator/denominator and center+log2(denominator), preserving L. There is no assumption that a prior END output is a valid unnormalized carry.

The exact Real target is the existing independent initial-array maximum/weighted-sum formula, Old.Whole.result / Correctness.expected, under its documented WithBot center interpretation, zero encoding of bottom, total Real division and logarithm. It remains separate from the native target: the all-masked initializer can yield Real denominator zero while the native NaN-alpha repair retains one. No IEEE representability or native-to-Real equality is asserted.

The native target must independently retain FP32 input/output/carry storage and scale ABI bits; default TF32 dots lowered to finite consecutive fixed-K8 matrix instructions; explicitly ordered max/sum trees; source multiplication/FMA orientation, NaN-alpha repair, exp2/log2, final division, and all output bytes. Same primitive/ISA interpretation ports are model boundaries, not deferred numerical transformation experiments. Compiler realization, Tensor/allocator APIs and launch/resource delivery remain external; the theorem must derive complete modeled source execution and source-result-to-target equality rather than assume either.

The source fix uses tl.cast(N_CTX, tl.int64) at the ordinary-window upper clamp so both constexpr NK=1 and runtime NK work. All 86 old source/proof/document files and both diagnoses are separately pinned and snapshotted. The candidate quote will explicitly connect this integer-only conversion to the mathematical source before reusing the old Real proofs. The existing native graph/byte theorems alone are not a full source-execution certificate, so a new native execution bridge and actual shared Tensor observations are required.
