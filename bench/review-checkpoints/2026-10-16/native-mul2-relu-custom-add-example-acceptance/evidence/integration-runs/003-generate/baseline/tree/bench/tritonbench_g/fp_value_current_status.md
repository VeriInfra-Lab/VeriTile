## 原接受范围与 dtype 范围

原23项中，全部已接受控制/阶段在新明确配置内保留；完整原wrapper枚举dtype域为 2 项（TMA与triton_matmul），仅新增明确dtype profile为 21 项。不是23项所有dtype都闭合。

完整软件profile按dtype范围分：{'selected_explicit_profiles_only': 21, 'new_source_declared_profiles': 3, 'complete_enumerated_wrapper_dtype_domain': 4}。源前端另分：{'shared_triton_dsl': 37, 'task_local_exact_ast': 3}。task-local SC 的并发模型不代表共享 DSL 或 GPU 内存语义。修复候选单列。

旧公共header逐文本保留不等于其引用定义语义未变。参考语义修复按单独的 receipt、复核和所有修改源码哈希核对；未完成的复核仍列为 pending。原41最大值迁移仅补充证据。

## 逐项复核结果

未满足项：0。原始源码仍缺：。仅候选合同：fp4_to_bf16_conversion。

Q/K 有理数缩放、Linear ReLU/identity、row-major布局及active-defined转换是显式附加特例，不能补齐全域阶段。Flash Phi 的 maximum recurrence 是恒等式，不是执行合同。

SGMV 原 Python singleton-tuple 仍编译失败，已接受 body 的源级值合同与去逗号候选编译图分开。Linear fast_gelu 原源码的 constexpr 失败亦保留。

原41项的 maximum 迁移与全库核心变化只可作为补充源码/重编证据，不回写旧登记模型角色。新字段不接受 FPCorrect 文件存在作为 source admission。

```sh
python3 bench/fp_value_extensions.py --check
```
