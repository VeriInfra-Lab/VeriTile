# triton_mul2 finite-source acceptance candidate

This additive package is pending independent substantive root review. It makes no acceptance increment and does not modify repository sources, Git, or prior frozen candidates.

The public specification is `TritonMul2Finite.triton_mul2_finite_source_outcomes` in `after/bench/tritonbench_g/triton_mul2/FiniteCorrect.lean`. Eight Lean modules connect both unchanged seven-statement kernel ASTs to finite scalar operations, complete tile loads and concrete byte stores, an independent last-write result, complete exactly-once program schedules, and both host wrappers. The package includes 4,648 schema2 cases and an exact numerical delta of 64 bindings in four floating multiplication families. Integer and Boolean behavior is concrete; Boolean storage writes raw bytes0/2.

The model retains the native annotated-i32 size cast for every Torch numel below2^63, per-operation i32 index wrap, signed comparison and u64 pointer wrap. It does not assume numel<2^31 or logical contiguity. At numel2^31 all lanes are provably masked and no byte permission/value premise applies. Empty launches still run native preparation and pointer setup. Out-of-place allocation metadata, preserve-format strides, zero bytes and exterior frame are unconditional; in-place returns the exact input object. Input strides do not enter the source kernel addresses.

Only fp16, bf16, fp32 and fp64 storage-width multiplication by exact literal2 remains numerical. There are no admitted float-to-integer conversions or undefined scalar conversions to exclude. All22 canonical dtype routes are recorded:13 admitted,5 binder rejects,2 fnuz architecture rejects and2 fp8 backend arithmetic rejects. Both wrappers' allocation/division/binder/frontend/backend/grid/pointer/launch error order is explicit. Access, missing-byte and ownership observations claim no native trap, race winner, rollback or post-failure memory.

Native evidence comprises78 offline records:30 complete compiles,42 rejections and6 frontend-only passes. The12 supplemental records confirm both fp8 backend rejections at B1, B512 and B1024.
