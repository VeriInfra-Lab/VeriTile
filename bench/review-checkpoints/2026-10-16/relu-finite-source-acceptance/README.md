# ReLU finite source acceptance

Five additive modules connect the original ReLU wrapper and every canonical
dtype route to actual typed/fp64 grid execution, returned metadata, source views,
finite pointers/masks and frames. The safe CUDA sm90 domain includes N=2^31;
larger index overflow remains explicit. All 17 profiles, 340 outcome cases and
12 numerical families / 84 ports are bound to the public execution statement.
Numerical conformance remains deferred, and GPU correctness is not established.

The source writes only pid0. For N>1024 the remaining output stays arbitrary
allocation contents. Safe noncontiguous views have physical flat-prefix behavior;
this is not a false logical elementwise ReLU claim. All original failure evidence
and the historical baseline are preserved. Integration results follow the actual
current catalog, schema2, exact numerical and build checks.
