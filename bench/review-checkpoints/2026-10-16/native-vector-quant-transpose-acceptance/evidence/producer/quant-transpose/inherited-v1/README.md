Complete finite quant_transpose_kernel acceptance proposal

The public statement is QuantTransposeFinite.quant_transpose_finite_acceptance in bench/tritonbench_g/quant_transpose_kernel/FiniteAcceptance.lean. Eleven modules compile and pass module-wide axiom audits. This is the only new public specification; intermediate results are ordinary audited theorems. The result, conversion-domain, and physical result predicates are audited independent of execution.

The model executes the full logical-view abs → whole-tensor max → unsqueeze → 1.0/maximum → exact 2D unpack → fresh CUDA int8 allocation → stride assertions → actual grouped 1D grid → return (out, original maximum). Return shape [N,M], strides [M,1], offset zero, physical extent, maximum shape [1], original maximum scalar-region alias, producer cells, and source-visible external frame are explicit. Input offsets are row*stride_am+col*stride_an relative to data_ptr; backing storage offset, length, base address, byte widths, and all allocation intervals are concrete domain fields.

PhysicalBinding connects actual allocation bases, capacities, alignment, device ownership and access permissions to the typed source model. In particular, output belongs to the current CUDA allocation device, which need not be the input device; kernel-read permissions on input and inverse remain explicit. initialBytes is the actual allocation snapshot, and outputInitialWords ties fresh output contents to that snapshot. host_physical_preparation proves the two host scalar word writes establish the starting byte representation. output_store_commutes and the lane/grid/trial execution theorems replay every actual output byte mutation across all successful launches. PhysicalStores proves intermediate logical and byte frames, and the input/inverse load lemmas tie operands to their byte representations. This covers live source-visible memory and trusted typed primitive mechanics, not allocator, MMU or GPU internals.

The original grouped formula is preserved: pid_m uses pid % group_size. Partial final groups may rotate rows. FiniteMapping proves a rotated inverse, bounds, and injectivity. FiniteGrid proves masked lane execution, all ordered programs, complete coverage, active output ownership, and every finite sequence of actual autotune entries followed by the selected final launch. The two original Config objects are identical 128×128/GROUP_M8/warps4/stages3; both remain distinct enum entries. The actual installed autotuner was instrumented without GPU launches: both entries benchmark, repetitions see prior writes, resource rejection falls back, and cache hits execute only the selected final launch.

The eight CUDA admitted storage dtypes are bool, uint8, int8, int16, int32, int64, fp32, fp64, with Torch default floating dtype fixed to fp32. The 22-profile inventory retains exact CUDA/CPU differences, empty maximum, wrong-rank unpack, input stride assertion, complex signature, half/bfloat16 llrint-overload, and CPU pointer rejections.
