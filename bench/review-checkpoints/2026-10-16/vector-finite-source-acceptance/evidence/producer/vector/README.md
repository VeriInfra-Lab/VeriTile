# Vector addition finite source acceptance candidate

This additive package connects the unchanged `vector_addition.py` wrapper and kernel to all 189 existing typed execution routes and all 100 canonical frontend rejections. It proposes finite original-source acceptance under the repository standard. Acceptance remains pending independent root review and integration; native correctness and numerical validation are not claimed.

The public specification is `VeriTile.Bench.TritonBenchG.VectorAddition.Finite.vector_addition_finite_source_outcomes` in `after/bench/tritonbench_g/vector_addition/FiniteCorrect.lean`. Allocation failure, CUDA assertion failure, first signature rejection, addition rejection, and successful execution are composed in source order. Success constructs an actual existing typed grid execution; no launch-success or final-value oracle is a premise.

The six additive modules prove concrete dtype-width pointer arithmetic, actual storage-offset and data-pointer relations, the signed-i32 multiply/add/mask, 64-bit pointers even for masked tails, active byte extents, natural alignment, output-cell ownership, source tile loads before stores, independent values, read-only input preservation, exterior byte frames, and output invariance under arbitrary complete active-lane schedules. The selected route's scalar computation is each existing source `resultCell`, or the exact fp64 typed result. Raw bool bytes retain the source i8 store behavior.

`TensorMetadata` is the explicit trusted Torch metadata interface: storage base, storage byte extent, data pointer, and actual `empty_like` preserve-format output strides. `SafeAPI` binds those queries to the views and returned metadata; no contiguity or copied-stride rule is assumed. `MemoryPrimitives` supplies ordinary typed storage reads/writes and their local laws. `MemoryApplicable` records the concrete launch device, stable readable input bytes and readable/writable output bytes. Implementing Torch, an allocator, MMU, GPU scheduler, or redundant byte codec is outside the stated standard.

The source traverses linear storage from each actual `data_ptr`; it ignores tensor strides and `y.numel()`. The new finite domain therefore allows `y.numel() < x.numel()` when the backing allocation covers the requested span. Both inputs may alias. It does not assert Torch elementwise addition for arbitrary layouts. Output comes from the actual allocator object, with its dtype, shape, number of elements, device, zero storage offset and preserve-format stride result.

`ValueDomain` is a genuine defined-value restriction, not a numerical deferral. Shared mixed integer-output conversions and nine fp64 integer/bool-output routes must have defined active conversions. Twenty fp64 floating-output routes have that condition automatically. Unsafe backing spans, missing permissions, cross-device access, pointer wrap, misalignment and undefined conversions remain outside successful applicability; no native rollback, poison or invented exception is assigned to them. `evidence/domain-review.json` records the complete boundary.

Verification comprises six clean final-path Lean builds, 40 named clean-axiom checks, one independent-reference check, and 194 unchanged imported project sources. The frozen source frontend matrix has 289 cases: 189 generated, 64 signature rejections and 36 addition rejections. Its ordinary `debug=false` target emits no device assertions, despite dead overflow-sanitizer arithmetic. CPU-only evidence covers 10 view examples, 68 dtype/layout metadata examples, 128 independent source-memory/schedule cases and nine index boundaries; no GPU run was performed.

`evidence/scope-row-proposal.json`, `evidence/catalog-supplement-task.proposed.json`, and `evidence/numerical-authority-delta.json` provide schema2 proposals with 2,601 exact cases and 616 scalar ports in 43 families. `authority_adapter.py` requires independently pinned producer and root-review receipts, binds every module, imported helper, source, frontend artifact and statement, and preserves all existing authority. `check_authority.py` exercises this in a synthetic fixture: all 616 missing-port mutations and six receipt/review/helper/TTIR/queue/self-review mutations fail. The unchanged whole-queue equality check passes for that fixture. This is an adapter test, not an independent root review.

`evidence/queue-payload-proposal.json` is explicitly a payload proposal without established review input pins. Root must integrate the frozen package and independent review, invoke `extend_vector_authority`, regenerate via the unchanged `extend_queue`, and run the normal global checks. Do not insert the proposal directly as authoritative queue state.
