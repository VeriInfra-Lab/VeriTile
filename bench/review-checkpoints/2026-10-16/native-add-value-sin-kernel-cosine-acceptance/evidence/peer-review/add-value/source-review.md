## Full host extents and actual addresses

Host numel is any nonnegative signed64 extent. The original grid uses that unnarrowed value, while N is extracted as i32 even at n=1. Independent compilation of extractI32 checks 16 boundaries, including both signed-minimum residues, grid threshold neighbors and 2^63-1, and confirms OverflowError at 2^63. Fourteen original binder/backend extent profiles were independently replayed.

Lane arithmetic wraps in i32 before the signed mask comparison. Address formation sign-extends the offset, multiplies by the storage byte width and wraps at 64 bits. The master has no no-wrap or requested-span precondition. Negative and repeated requests therefore remain actual modeled requests, subject to access/ownership observations. At n=2^31 every mask is false and the supported launch returns the identical allocation and unchanged memory without input access/value premises. Independent symbolic proof identifies the exact grid limit n <= (2^31-1)*1024; n=2^41 fails the signed-grid parser before pointer packing.

Torch storage/data pointers are separate from kernelArgumentPointer and mapped Buffer base/data. Successful pointer extraction supplies the actual mapped launch addresses; owner metadata does not determine current-device accessibility. The trusted buffer permissions are indexed by the actual launch device. The source uses the extracted pointer and accesses the mapped memory coordinate system.

The unconditional TensorBinding fields are total metadata, not unconditional claims of extraction success. A branch that never consumes successful extraction can use unused ordinary affine witnesses. On successful packing they denote the actual extracted pointer and mapped allocation. Independent regressions demonstrate CUDA assertion and pointer-stage failures without consuming metadata, and a valid empty CPU view with nonzero storage offset, nonempty backing capacity and null data pointer. Forty-nine additional actual CPU-wrapper cases confirm allocation-before-assertion and retained actual metadata, without reaching extraction. This matches the already reviewed pointer-totalization interpretation.

## Memory, execution and scheduling boundary

Memory loads are ordinary typed finite words tied to presence of all requested bytes and local byte congruence. Missing bytes cannot become a default scalar. Pure width-specific encoding, store-byte and exterior-byte laws characterize stores. No arbitrary tagged carrier is assumed to round-trip through narrower storage. These are explicit typed-load/store primitives; the proof does not replace them with a numerical or whole-kernel result callback.

The source program and independent plan have different scalar definitions, connected by source_scalar. The plan samples initial memory. Fresh output and load/frame lemmas justify those snapshots across earlier stores. Input access, missing bytes, undefined conversion, output access and ownership conflicts are mathematical observations; they make no claim about a native trap, race winner, rollback, successful return or post-failure memory. Stores cover complete byte spans, and the owner ledger checks overlap within and across programs before a returned result is asserted.

The public launch chooses List.range(grid n), as the catalog's sequentially_consistent_schedule boundary states. It is not a theorem quantified over every native scheduler. The underlying grid_correspondence holds for any pid list, and an independent regression instantiates it without an order restriction. Fresh input frames prevent write/read interference; successful ownership checks prevent overlapping output spans. An additional clean-axiom proof shows disjoint stores commute at every output byte. No example of different legal complete orders changing a successful returned byte result was found. This review neither assumes increasing native scheduling nor claims a scheduler implementation proof.

Returned memory is characterized by the independent write plan, pure packing and reverse-last-write byte formula. Untouched bytes equal the arbitrary allocated bytes. Input/exterior preservation follows from bounds and freshness; allocation's exterior frame relates the returned frame to pre-allocation memory. An independent regression exercises overlapping-write byte lookup and an untouched address as a property of the general formula, without claiming that ownership-conflicting source execution returns successfully.
