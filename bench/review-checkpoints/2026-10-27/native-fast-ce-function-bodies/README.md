三种原始 JIT 和三个已有索引乘法候选共六份完整函数体逐句保留。调用类型、运行时参数、constexpr 和 libdevice 导入绑定在函数体外；原有显式转换、单行条件、函数签名和 decorator 保留。清单静态解析原 wrapper 的本地加载，要求被加载文件中的所有 JIT 都有对应项。

旧 Lean 额外添加的前向／分块存储转换已移除，内部执行及输出表达式同步修正。后向计算表达式的隐式指针转换仍在执行模型中保留。公开实数公式、输入范围、原生观测和 Tensor 结论通过实际源码重新证明；不假定任意浮点代数的转换恒等。
